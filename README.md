## Giới thiệu

BotItem là bộ ứng dụng Windows được lưu trữ trong repository này. Repo hiện có các tệp thực thi `QLTK.exe`, `DragonBoy250.exe`, thư mục dữ liệu `DragonBoy250_Data`, cùng các thành phần phụ trợ như `Guna.UI2.dll` và biểu tượng thương hiệu `logo.ico`.

> Lưu ý: Repository hiện cung cấp tập tin đã biên dịch và tài nguyên đi kèm. Do đó, hướng dẫn dưới đây tập trung vào việc chuẩn bị môi trường chạy, cách truy cập, sử dụng và hỗ trợ kích hoạt key theo kênh chính thức của TigoStudio.

## Yêu cầu hệ thống

- Hệ điều hành: Windows 7/8/10/11
- Tải đầy đủ các tệp trong repository, giữ nguyên cấu trúc thư mục
- Không xóa hoặc đổi tên các tệp `.dll`, thư mục dữ liệu hoặc biểu tượng thương hiệu đi kèm
- Có quyền truy cập vào thư mục giải nén
- Kết nối Internet để nhận hướng dẫn kích hoạt hoặc hỗ trợ từ admin

## Tải và cài đặt

1. Mở repository: https://github.com/nhannguyen2005/botitem
2. Chọn `Code` → `Download ZIP`
3. Giải nén ZIP vào một thư mục mới, ví dụ: `C:\BotItem`
4. Kiểm tra thư mục đã giải nén có đầy đủ các tệp sau:

```txt
BotItem/
├─ DragonBoy250.exe
├─ DragonBoy250_Data/
├─ Guna.UI2.dll
├─ QLTK.exe
├─ logo.ico
├─ README.md
```

5. Nếu cần kích hoạt bản quyền, hãy liên hệ admin trước khi thực hiện các thao tác quan trọng hoặc cần dùng tính năng đầy đủ.

## Hướng dẫn sử dụng cơ bản

1. Mở thư mục đã giải nén.
2. Chạy file `QLTK.exe` hoặc `DragonBoy250.exe` tùy theo phiên bản và mục đích sử dụng.
3. Nếu chương trình yêu cầu key kích hoạt, hãy nhập key được cấp bởi admin.
4. Làm theo hướng dẫn trên giao diện.
5. Khi hoàn tất, thoát ứng dụng bằng nút thoát trên giao diện.

> Không sao chép tách riêng file `.exe` ra khỏi thư mục gốc nếu chưa chắc chắn, vì các tệp đi kèm có thể cần thiết để ứng dụng chạy ổn định.
